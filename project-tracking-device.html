LoRa GPS Tracking Device

Long-range GPS tracking using LoRa (RYLR998), ESP32 firmware, NEO-6M GPS, OLED readout, and Python on the host for serial parsing plus live map views (Flask and Folium).

View on GitHub

Overview

A mobile transmitter reads live GPS from a NEO-6M module, shows it on an SSD1306 OLED, and sends latitude/longitude over LoRa. A stationary receiver bridges LoRa to USB serial; Python scripts parse packets and visualize the track on an interactive map (Folium-based refresh and/or a Flask server with live updates).

Architecture

[GPS + ESP32 + OLED]  ─LoRa─►  [ESP32 LoRa receiver]  ─USB─►  [Python + map]

Hardware

Transmitter: ESP32, NEO-6M GPS, RYLR998 LoRa, SSD1306 OLED.

Receiver: ESP32, RYLR998 LoRa (USB to computer).

Host: Python environment with pyserial, Flask, Folium as needed.

Protocol

  • Payload format: latitude,longitude
  • LoRa: AT-style send (e.g. AT+SEND=2,<length>,<payload>)
  • Receiver prints +RCV lines; Python extracts GPS strings

Software (repo)

  • transmitter.ino / receiver.ino — ESP32 firmware (TinyGPS++ on TX)
  • tracking.py, folium_tracking.py — mapping / visualization (see README for Flask variants if present)

Configure LoRa addresses (e.g. transmitter vs receiver), serial port (e.g. COM6), and baud (115200) to match your setup.

Limitations & future work

No encryption or CRC in the reference design; fixed serial settings; assumes a valid GPS fix before send. Possible improvements: validation, encryption, history storage, and a mobile-friendly UI.
