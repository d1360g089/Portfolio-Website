Self-Stabilizing Platform

Dual-axis platform with BNO055 sensor fusion, quaternion orientation, PD control, and real-time 3D modeling in VPython.

View on GitHub

Overview

This project is a dual-axis self-stabilizing platform built using an IMU sensor (BNO055), sensor fusion via complementary and quaternion filters, and PD control. The system models real-time 3D orientation using VPython and explores trade-offs in control design from bang-bang to PID.

Using Euler angles introduced gimbal lock and instability due to reliance on trigonometric functions such as arctangent. The project transitioned to quaternion-based orientation, which improved accuracy, eliminated gimbal lock, and enabled smoother rotational tracking—important for responsive real-time 3D modeling in VPython.

Real-time orientation was modeled in VPython for interactive 3D visualization from sensor data. On the control side, development moved from a simple constant correction (bang-bang) controller to proportional (P) control. The P controller reduced error but introduced jitter and oscillations at larger angle deviations, so a full PID loop was implemented. After testing, the integral term proved ineffective for this application, and the system was finalized as a PD (Proportional–Derivative) controller. The derivative term damped oscillations and improved responsiveness during rapid movements.

Through this project: hands-on experience with sensor fusion, quaternion math, control theory, and real-time system modeling—and a foundation for follow-on work such as a self-balancing robot on unstable dynamics.

How it works

  • Sensor: BNO055 (gyroscope, accelerometer, magnetometer)
  • Actuators: Two servo motors for pitch and roll
  • Filtering: Low-pass and complementary filter for orientation
  • Representation: Quaternions for smooth motion and accurate data
  • Control: PD control to keep the platform level

Repository layout

  • bno055/bno055.ino — Arduino firmware
  • bnodata.py — serial connection and data handling
  • sim.py — VPython 3D simulation

Components

  • Arduino Uno
  • BNO055 IMU
  • Two MG996R servo motors
  • Breadboard and jumper wires
  • Servo brackets
