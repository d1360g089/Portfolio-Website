Autonomous RC Car

Arduino-based platform with manual wireless control and autonomous obstacle avoidance: differential drive, nRF24L01 link, ultrasonic ranging, and BNO055 quaternion yaw for IMU-assisted scanning and turns.

View on GitHub

Overview

This project is an Arduino-based RC car that supports both manual wireless control and basic autonomous navigation. It integrates DC motors, nRF24L01 wireless modules, an ultrasonic distance sensor, and a BNO055 IMU to explore autonomy, sensor limits, and control on constrained embedded hardware—with emphasis on systems integration and real-time control.

Autonomous behavior

In autonomous mode the vehicle drives forward until the ultrasonic sensor sees an obstacle inside a set threshold. It then stops and performs a 360° rotational scan using yaw from the BNO055 (quaternion-based, avoiding Euler singularities). Distances are sampled at roughly fixed angular steps (~10°); the firmware picks the direction with the most clearance, rotates to that heading with IMU feedback, then resumes forward motion.

Control is a state-based flow: forward drive → detect obstacle → scan in place → choose best heading → reorient → drive again. Motors use PWM differential drive; turns use opposite wheel speeds.

Manual (RC) mode

Joystick axes are sent over nRF24L01 and mapped to left/right motor speeds for steering—useful for testing motors, latency, and baseline driving before tuning autonomy.

IMU and orientation

  • Sensor: BNO055
  • Representation: Quaternions → yaw for scanning and turns
  • Scope: Heading only, not full global positioning; drift and noise remain constraints without encoders or richer fusion.

Challenges (from the build)

  • Ultrasonic noise from angles and environment
  • IMU yaw drift on long scans
  • No wheel odometry
  • Blocking control sections and Arduino compute limits

Repository

Firmware includes car-side logic (e.g. AutonomousCar.ino) and transmitter code (Transmitter.ino) for the joystick controller. See the repo for the exact layout.

Components

  • Arduino Uno (class)
  • BNO055 IMU
  • nRF24L01 modules (TX/RX)
  • Ultrasonic distance sensor
  • DC motors and H-bridge drivers
  • Joystick modules, breadboard, chassis

Updated: Object Detecting Radar Scanner

To improve obstacle detection and navigation, I mounted an ultrasonic sensor onto a servo motor that performs a 180° sweep around the vehicle. During each sweep, the sensor records the distance to nearby objects at different angles. Using these measurements in polar coordinates (r,θ), I generated a real-time polar graph that maps detected obstacles as purple points based on their measured distance and angle. I then used a list to identify the minimum recorded distance and its corresponding angle, allowing the system to determine the closest obstacle in the environment. This nearest object is highlighted on the graph as a larger green point that updates continuously with each new scan.
